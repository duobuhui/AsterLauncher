# 游戏资料

客户端读取 [catalog.json](catalog.json)，与启动器版本更新独立。修改资料后增加 `revision`，合并到 main 即可生效。

- 卡池：稳定的 `gameId + key + phase`，展示名称、起止时间、对应武器池和官方公告来源。时间使用带时区的 ISO 8601；未公布结束时间填 null，不推算。
- 图片：PNG、JPEG、WebP，提供 SHA-256、大小、来源及权利说明。文件放在本目录，单张最多 8 MiB，总计最多 64 MiB；仅缓存到启动器数据目录，不在打开记录页时下载。
- 预留资料：兑换码（奖励、有效期、地区、平台）、前瞻节目、活动日历和维护公告。当前未接入首页展示。只收录官方可核实信息，不填示例兑换码。

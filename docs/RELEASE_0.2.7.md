# AsterLauncher 0.2.7

- 终末地默认由官方启动器接管。展开启动选项 → 启动方式，为当前官服或 B服选择并确认官方启动器，再在官方启动器中开始游戏。等待时限可选 1、3、5 分钟；取消等待不会关闭游戏或官方启动器。
- 新增默认关闭的“无界面启动桥（实验性）”，使用本机签名可信的官方组件承接启动来源，不修改游戏文件。兼容性仍需实际游戏验证；失败后不会自动重复启动，可手动切回官方启动器接管。
- 保留原游戏路径、两服独立配置、自定义接管和伴随工具。游戏时长仍按真实游戏进程记录；云游戏入口保持原有行为。

已通过自动化回归、隔离进程生命周期及实际 WinUI 检查。未操作用户游戏或自用安装，未宣称完整真实游戏启动验收。0.2.6 可使用文件差量升级，其他版本使用最新完整包；保留现有 Data。

# AsterLauncher 0.1.7-beta

- 终末地可在游戏外修改分辨率和窗口模式，保存、切换画质方案，并查看游戏照片。
- 终末地抽卡卡片显示卡池开放时间和对应专武申领记录，重构池按期分开。
- 原神、星穹铁道、绝区零增加 B服下载维护与独立安装；相同资源可在同卷 NTFS 上共享。
- 下载前可确认目录、语言和资源复用选项，修复检查、下载及缓存清理时的界面卡顿。

解压完整 ZIP，运行 AsterLauncher.exe。0.1.3 及以上可在设置中更新；0.1.2 及更早版本需使用迁移工具。

终末地画面设置由两服共用，修改前请关闭游戏。画质方案保存游戏已有设置，不提供尚未核实的画质档位映射。使用官方启动器维护共享资源前，请先解除共享。两服完整安装后的启动、真实预下载窗口仍待进一步验证。

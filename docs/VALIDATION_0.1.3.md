## 硬链接与实际空间

E 盘 NTFS 隔离样本中，先生成两份 1,048,577 字节随机资源。共享前文件 ID 不同；共享后两者卷序列号为 1,222,258,029，文件 ID High/Low 均为 65,536 / 272,249，链接数均为 2。使用 GetFileInformationByHandleEx 的 AllocationSize 去重统计，分配空间从 2,105,344 字节降至 1,052,672 字节，实际减少 1,052,672 字节。config.ini 仍具有不同文件 ID。

通过统一提交层替换官服资源后，两服 ID 分离，B 服原始 MD5 保持；再删除官服目录项，B 服仍可读取且 MD5 不变。记录在本地 .artifacts/storage-evidence/v0.1.3-verified/hardlink-evidence.json，可运行 eng/probes/EndfieldStorageProbe 重新生成。自动化测试另外覆盖共享失败的独立回退、同大小损坏和解除意外硬链接。

以上证明文件系统共享及 AsterLauncher 写入隔离，不能证明真实客户端运行时所有 .chk 都不会修改。候选范围及外部维护前解除共享的边界见研究文档和发布说明。

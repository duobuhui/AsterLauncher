# 0.2.0-beta

- 游戏资料独立更新：卡池名称、时间和图片从公开 GitHub 资源目录获取，支持本地缓存和离线回退。
- 全局改用微软雅黑 UI 字体；卡片深浅色与主题颜色分开设置。
- 页签标题移至顶部导航右侧，终末地卡池名称与时间并排显示，精简维护菜单和卡片文字。
- 游戏设置增加已有安装的服务器确认入口。
- 修复已安装、运行中筛选，以及从游戏库、设置、日志返回游戏主页的问题。

完整解压后运行顶层 AsterLauncher.exe，保留 App、MigrationTools 文件夹和原 Data。0.1.7-beta 可通过启动器更新。

兑换码、前瞻、活动和维护公告已预留资源字段，暂未在首页展示。图片权利归游戏发行商。

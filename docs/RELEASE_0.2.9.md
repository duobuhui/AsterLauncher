# AsterLauncher 0.2.9

- 统一各页面玻璃面板的材质、边框、圆角和与顶栏的间距。
- 抽卡记录的账号、页签、同步、导入和导出集中在固定右上操作区；窄窗口通过“更多”保留操作，滚动记录时工具区保持可见。
- 抽卡统计使用清楚的指标卡，区分总抽数、出货数量、平均出货抽数和当前已垫；不完整历史与未知判定保留明确说明。
- 星穹铁道 21/22 类别显示为 Fate 联动角色/光锥跃迁，未知类别仍保留独立显示，不推测特殊保底规则。
- 核对终末地官方公开资料，补充活动详情中的内容更新时间，资源目录更新至 revision 2026102101。

0.2.8 可使用文件差量更新，其他版本按匹配情况使用完整包；保留原 Data。下载完整包后解压并运行顶层 AsterLauncher.exe，保留 App 和 MigrationTools 文件夹。

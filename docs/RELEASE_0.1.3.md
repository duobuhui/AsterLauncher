## 新增

- 终末地官服/B服独立安装、更新、修复与预下载。
- 在启动按钮右侧展开面板切服，同步图标、目录和版本。
- 进入游戏页检查更新，主按钮显示更新入口或下载进度。
- 同卷 NTFS 资源硬链接共享、存储统计及解除共享。
- 多文件发行包、文件差量更新和独立迁移工具。

## 下载与升级

新安装下载 `AsterLauncher-v0.1.3-beta-win-x64.zip`，完整解压后运行顶层 `AsterLauncher.exe`。

**从 0.1.2 升级：**

1. 退出旧版，下载完整包、同名 `.zip.sha256` 和 `AsterLauncher-v0.1.3-beta-migration-tools.zip`。
2. 将迁移工具解压到旧安装目录之外的同一卷，运行 `AsterLauncher.Migrator.exe`。
3. 选择旧安装目录和完整 ZIP。原数据保留，旧程序备份在 `MigrationBackup`；完成后仍从原目录启动。

0.1.2 内置更新器不能直接安装新布局。0.1.3 起支持多文件整包和差量更新。

## 使用说明

- 终末地维护功能为 Beta，预下载仅在官方开放时可用。
- 硬链接共享要求同卷 NTFS。使用官方启动器维护前，请关闭两服游戏并解除共享。
- HDiff/VFS 原生增量目前使用目标清单逐文件同步回退。

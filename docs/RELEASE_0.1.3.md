# AsterLauncher 0.1.3-beta

本版将终末地官服与哔哩哔哩服放在同一个游戏页面中。点击“开始游戏”右侧箭头，在原有启动选项面板选择服务器、设置独立目录、检查文件、修复及管理共享资源。切服立即同步图标标识、目录、版本和主按钮状态；下载任务继续绑定最初选择的渠道。每次进入终末地页面检查更新，发现新版本时主按钮改为“更新游戏”，下载时显示进度并可暂停。

安装和更新使用官方实时元数据及加密完整清单，按目标文件下载与校验；不依赖存档签名地址。提供有限并发、内容缓存、续传、签名刷新、同大小损坏检测、未完成任务恢复和最终校验。默认目录按设置中的游戏下载目录创建官服/B服子目录。旧路径只有在渠道配置与入口哈希相符时才识别渠道，其他旧安装需明确选择。

两套物理安装目录可以共享经过两服清单与本地内容校验的 VFS .chk 候选资源；配置、程序、索引和用户状态保持独立。界面统计实际卷标识与文件 ID 相同的硬链接，并估算节省空间。更新和修复始终生成独立文件，再替换当前渠道的目录项。跨卷、非 NTFS 或硬链接失败时使用独立文件。官方启动器或游戏自身维护不受这层替换逻辑约束；交给外部程序维护前请关闭两服游戏并执行“解除共享”。真实客户端运行时的 .chk 不可变性仍需扩大验证，不能据此承诺所有外部维护行为安全。

预下载仅在官方开放有效内容时可用，不更改当前游戏文件和版本。正式更新重新核对渠道、源/目标版本及内容，复用已验证缓存；补丁中的完整文件通过独立暂存、密码/分卷解压和目标哈希校验后使用。HDiff/VFS 增量输出采用目标完整清单逐文件同步回退，原生增量应用没有在本版宣称通过实机验证。

## 下载与迁移

新安装下载 `AsterLauncher-v0.1.3-beta-win-x64.zip`，完整解压后运行顶层 `AsterLauncher.exe`。程序与运行文件放在 `App` 和 `MigrationTools` 中，数据位于原有 `Data` 或自选位置。

0.1.2 的更新器只能接收单 EXE 包，需要一次迁移：退出旧版，下载完整包及同名 `.zip.sha256`，另解压 `AsterLauncher-v0.1.3-beta-migration-tools.zip` 到旧目录之外的同一卷；运行其中的 `AsterLauncher.Migrator.exe`，选择旧安装目录与完整包。旧程序保存在 `MigrationBackup`，原数据不移动；以后仍从原位置的 `AsterLauncher.exe` 启动。不要把迁移工具放进待替换的 `App` 或 `MigrationTools` 目录。

0.1.3 起使用 `aster-update-v2.json` 与多文件更新：差量包仅包含变化文件，完整包和差量包都逐文件核验、暂存后提交并保留上一版备份。此次没有提供可由 0.1.2 旧更新器直接安装的差量包。

## 验证范围

自动化检查覆盖真正的 NTFS 硬链接、单服安全替换/删除、解除共享、路径防护、下载续传与缓存损坏、旧配置、预下载与正式更新缓存复用、分卷和加密 ZIP、任务中断恢复，以及迁移和多文件更新的数据保留。WinUI 页面已在隔离目录运行、切服并截图检查。

应用实际使用的传输服务已重新取得两服实时官方清单，并完成官方小文件下载与 MD5 校验；当前响应两服均为 1.5.3，`pre_patch` 均为空。没有自动下载两份几十 GB 的客户端，**两服完整安装后的实际游戏启动、真实预下载窗口及正式增量样本仍需验收**。本版是 beta；上述自动化样本和小文件验证不能替代这些实机项目。

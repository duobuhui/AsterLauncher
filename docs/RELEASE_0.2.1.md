# 0.2.1-beta

- 终末地新增“版本日历”：默认用横向时间轴对照卡池、活动、版本更新、维护和前瞻。名称、持续日期、今日线和跨月标记直接可见；也可切换月历、按类别筛选并打开官方公告。
- 同页显示官方来源兑换码、奖励和有效期，支持一键复制；没有已核实的未过期兑换码时显示空状态。日历与兑换码随“游戏资料”独立更新，断网时使用本地资料。
- 下载任务明确区分文件校验、另一服资源复用、下载和应用阶段，显示当前文件及处理量。速度仅统计新传输的数据，校验时不再保留下载速度。
- 统一设置、辅助工具、启动方案和日历的玻璃卡片、按钮及小标题样式，兼顾浅色与深色卡片。

日历时间统一为北京时间（UTC+8），时间轴按日展示；只公布日期的安排不推算小时，未公布结束时间时仅标出起始点。日历和兑换码目前仅适配终末地，兑换结果以游戏为准。

0.2.0-beta.1 用户可在设置中检查更新。完整包继续使用顶层 `AsterLauncher.exe`、`App` 和 `MigrationTools` 布局；请保留原来的 `Data` 及数据位置文件。更新后可点击“更新资料”取得后续公开安排与兑换码。

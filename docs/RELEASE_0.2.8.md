# AsterLauncher 0.2.8

- 终末地首次使用时提示选择启动方式，说明新版启动限制；默认推荐打开官方启动器，全部选项一屏显示，无需滚动。
- 实验启动方式遇到官方组件要求管理员权限时，先确认本次授权，再显示 Windows UAC。取消即可停止，Aster 主界面保持普通权限。
- 改善管理员权限游戏的进程识别，避免游戏已经启动仍继续等待。
- 游戏临时目录按安装路径固定保存，与每次清理的编译目录分开，避免重复启动时临时状态目录变化。

终末地默认仍由官方启动器接管，需要在官方窗口点击“开始游戏”。实验方式需自行开启，兼容性取决于官方客户端；失败时请先检查游戏是否已打开，再切回官方接管。两服分别保存选择，已有自定义接管方案保留。

下载完整包后解压，运行顶层 `AsterLauncher.exe`，保留 `App` 和 `MigrationTools` 文件夹。0.2.7 可使用文件差量更新，其他版本会按匹配情况使用完整包更新；更新保留原 Data。无需额外下载迁移插件。

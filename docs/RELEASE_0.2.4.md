# 0.2.4

- 抽卡记录页增加统一账号切换，记录、汇总、统计详情和校对使用同一账号。原神、星穹铁道、绝区零按档案中的 UID 切换；切换游戏后保留本次打开时的选择。
- 终末地支持新建和切换独立的本地账号档案。原有记录继续使用原文件；同步和导入前确认目标档案。官方记录没有可靠账号标识时，由用户核对当前游戏账号，启动器不自动推断身份。
- 不支持抽卡记录的游戏隐藏对应入口，切换游戏后返回可用页面。
- 修复星穹铁道等游戏高抽数柱子复用后颜色异常；完整出货间隔随抽数逐渐变暖，高抽数保持红色。缺失历史仍明确显示本地记录下界。
- 散点随抽数和同位置记录数量增强大小与可见度，保留真实位置、全部记录及历史不完整标记。
- 修复崩坏3找到现有 EXE 后未关联维护目录的问题；同版本、未知版本及本地较新版本不再错误提示更新或引导另建目录。

终末地日历和卡池资料继续独立更新。使用说明见启动器内账号提示；更新仍保留原 Data 和最近一版程序备份。0.2.3 可使用文件差量直接升级，其他版本使用最新完整包。

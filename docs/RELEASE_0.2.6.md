# AsterLauncher 0.2.6

- 本地游戏按实际进程启动时间记录时长，支持先开游戏再开启动器。退出启动器后，轻量计时进程继续观察已发现的游戏，游戏结束后自动退出；下次打开合并记录且不重复累计。
- 保留旧版累计时长，按每天实际覆盖时段更新热力表，修正跨周统计；云游戏和模拟器不计时。未被发现就已退出的游戏无法补记，断电或强制结束计时进程时保留最后已确认记录。
- 修复计时与修改设置并发保存可能覆盖记录的问题；重复打开同一数据目录会恢复已有窗口，避免多个窗口写配置。计时仍在进行时明确阻止迁移数据目录。
- 修复绚丽异彩卡池的底图映射，内置资料更新至 2026101502；0.2.5 也可单独更新资料恢复底图。

已通过自动化回归与隔离 WinUI 关闭、重开及后台计时检查。实际游戏进程的权限与兼容情况仍需用户实测。0.2.5 可使用文件差量升级，其他版本使用最新完整包；保留现有 Data 和最近一版程序备份。

# 0.2.3

- 修复 0.2.2 在配置较大时读取失败，随后显示欢迎页并覆盖时长、隐藏列表和游戏路径的问题。读取失败现在会停止写入并显示恢复提示。
- 正常保存自动保留一份有效配置备份。设置 → 窗口与路径 → 记录恢复，可查看备份概况后确认恢复。
- 已受影响的用户可使用“从日志恢复时长”，找回本地日志中已完成的游戏会话。先预览再合并，不改变其他设置，也不会重复累计；没有日志的历史无法恢复。
- 修复已选择服务器时，自动查找明明找到星穹铁道等游戏却未绑定安装路径的问题。只在本地安装信息能明确确认游戏和渠道时绑定。

0.2.2 用户可直接检查更新，使用文件差量升级。更新后若记录已被旧版覆盖，请使用上述恢复入口；游戏路径可重新查找，隐藏列表需按个人习惯重新设置。抽卡档案、游戏文件不参与配置恢复。更新仍只保留最近一版程序备份，不提供独立迁移工具包。
